# 세잇단서 MVP

매일 세 개의 단서로 공통 정답을 맞히는 독자 데일리 웹게임입니다.

## 실행
`index.html`을 브라우저로 열면 동작합니다.
실제 배포는 GitHub Pages, Cloudflare Pages, Netlify, Vercel 등 정적 호스팅에 올리면 됩니다.

## 법적 리스크를 낮추기 위해 반영한 원칙
- 타 게임의 이름, 로고, 화면 캡처, 캐릭터, 문제 데이터, 카피 문구를 사용하지 않음
- 외부 이미지, 폰트, 음악, 효과음 없이 제작
- 문제 데이터 자체 작성
- 회원가입/개인정보 수집 없음
- 게임 기록은 브라우저 localStorage에만 저장
- 광고 영역은 승인 후 실제 광고 코드로 교체
- 정식 서비스명 확정 전 KIPRIS 상표 선행검색 권장

## 출시 전 체크
1. KIPRIS에서 서비스명 동일·유사 상표 검색
2. 도메인명 및 SNS 계정 중복 확인
3. 애드센스/분석 도구를 추가하면 개인정보처리방침 갱신
4. 문제 데이터는 직접 작성하거나 이용허락/라이선스가 명확한 자료만 사용
5. 영화/드라마/캐릭터/브랜드 기반 문제는 공식 이미지·대사·로고 사용 금지
